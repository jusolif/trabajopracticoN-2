# Primer Proyecto de Portafolio Personal
1. Descripción del proyecto: Este proyecto consiste en el desarrollo de una aplicación interactiva en Streamlit para realizar un Análisis Exploratorio de   Datos (EDA) sobre el dataset BankMarketing.csv. El dataset corresponde a una institución financiera que busca analizar el comportamiento de sus clientes frente a una   campaña de marketing y comprender los factores relacionados con la aceptación de la campaña.
